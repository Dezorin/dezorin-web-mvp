سياسة الخصوصية

آخر تحديث: 22 أغسطس 2026

تحترم Dezorin خصوصية مستخدميها، وتوضح هذه السياسة طبيعة البيانات التي تتم معالجتها عند استخدام الأداة وكيفية التعامل معها.

1. البيانات التي نجمعها

تتم معالجة البيانات اللازمة لتشغيل الخدمة، وتشمل:

  • بيانات الحساب، مثل البريد الإلكتروني.
  • بيانات المشاريع التي يدخلها المستخدم، بما في ذلك اسم المشروع، معلومات المشروع، إجابات العميل، والبيانات اللازمة لتنفيذ مراحل الأداة.
  • النتائج الناتجة أثناء مراحل التحليل والتفكيك والاستكشاف والاكتشاف وفكرة تنفيذ الشعار والتقرير.
  • البيانات التشغيلية اللازمة لإدارة الاستخدام والرصيد والمشاريع.

2. استخدام البيانات

تُستخدم البيانات لتشغيل Dezorin، وتنفيذ مراحلها، وحفظ مشاريع المستخدم، وإدارة الحساب والرصيد، والمحافظة على سلامة الخدمة وتحسين أدائها.

لا تستخدم Dezorin بيانات مشاريع المستخدم أو عملائه لأغراض مستقلة عن تقديم الخدمة له.

3. معالجة البيانات عبر مزودي الخدمة

تُرسل البيانات اللازمة لتنفيذ مراحل المعالجة بالذكاء الاصطناعي إلى OpenAI عبر واجهة API لتوليد النتائج المطلوبة داخل Dezorin.

ووفقًا للمعلومات المنشورة حاليًا من OpenAI، لا تُستخدم بيانات API لتدريب نماذجها افتراضيًا، مع خضوع معالجة البيانات لسياسات وشروط مزود الخدمة المعمول بها.

تعتمد Dezorin كذلك على Supabase وخدمات الاستضافة والبنية التحتية اللازمة للمصادقة وتخزين بيانات الحساب والمشاريع وتشغيل الخدمة.

وبناءً على مواقع البنية التحتية لمزودي الخدمة، قد تتم معالجة أو استضافة بعض البيانات خارج المملكة العربية السعودية.

4. حماية البيانات والوصول إليها

تتخذ Dezorin إجراءات تقنية وتنظيمية معقولة لحماية البيانات وتقليل الوصول غير المصرح به إليها.

صُممت صلاحيات النظام بحيث لا يستطيع المستخدم الوصول إلى مشاريع مستخدم آخر من خلال حسابه.

ومع ذلك، لا توجد وسيلة إلكترونية أو خدمة عبر الإنترنت يمكن ضمان أمنها بصورة مطلقة.

5. بيانات عملاء المستخدم

عند إدخال المستخدم معلومات تخص عميله أو مشروع عميله، فإنه يقر بمسؤوليته عن امتلاك الصلاحية أو الأساس النظامي المناسب لإدخال هذه المعلومات ومعالجتها من خلال الخدمة.

يُنصح بعدم إدخال معلومات شخصية أو سرية لا يحتاجها المشروع أو مراحل التحليل.

6. الاحتفاظ بالبيانات وحذفها

يتم الاحتفاظ ببيانات الحساب والمشاريع بالقدر اللازم لتقديم الخدمة وتشغيلها والوفاء بالمتطلبات النظامية أو التشغيلية ذات الصلة.

يمكن للمستخدم طلب حذف حسابه وبيانات مشاريعه من خلال وسيلة التواصل الرسمية المتاحة لدى Dezorin، وتتم معالجة الطلب وفق المتطلبات النظامية والتقنية المعمول بها.

7. التغييرات على سياسة الخصوصية

قد يتم تحديث هذه السياسة عند تطوير الخدمة أو تغير المتطلبات التشغيلية أو النظامية. وسيظهر تاريخ آخر تحديث في أعلى هذه الصفحة.

8. التواصل

لأي استفسار أو طلب متعلق بالخصوصية أو البيانات، يمكن التواصل مع Dezorin عبر وسيلة التواصل الرسمية المعلنة في الخدمة.
